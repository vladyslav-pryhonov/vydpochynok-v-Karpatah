# Плай і Пара: демо-сайт (портфоліо)

Демонстраційний сайт бази відпочинку «Плай і Пара» (три хатинки з чаном і сауною в Карпатах).
**Це демо-проєкт:** бренд, ціни, рейтинг, відгуки й контакти вигадані, реальних клієнтів немає.
Сторінки закриті від індексації (`noindex`).

## Склад
- `index.html`: головна (бронювання з календарем, карта, галерея, відгуки, FAQ);
- `smereka.html`, `yalivets.html`, `kedryna.html`: сторінки хатинок;
- `contacts.html`: контакти;
- `css/base.css`: шрифти й спільні змінні; решта стилів вбудована в кожну сторінку;
- `fonts/`: Spectral, Space Grotesk, Karla (SIL OFL), самохостинг, підмножини cyrillic і latin;
- `img/`: фото у форматі WebP (оригінали з Unsplash, ліцензія Unsplash).

Статичний сайт без збірки: відкривається будь-яким статичним сервером (GitHub Pages підходить).
